# Accounts Explorer Web Application (نظام حسابات إكسبلورر - تطبيق الويب)

نظام محاسبي وإداري سحابي متكامل لإدارة الحسابات، نقاط البيع (POS)، فواتير المشتريات والمبيعات، المخزون، والقيود اليومية التلقائية مع دعم التحديث التلقائي عبر GitHub.

---

## المميزات الرئيسية / Key Features
- **إدارة فواتير المبيعات والمشتريات**: مع القيود المحاسبية للجرد المستمر، حساب الأرباح، وتخصيص الحقول الاختيارية (الكمية المجانية، تاريخ الانتهاء، السيريال نمبر، والضريبة).
- **إدارة نقاط البيع ومزامنتها (POS Management)**: شاشات مبيعات تفاعلية، شاشات عمليات وإحصائيات يومية، وتصميم وطباعة ملصقات الباركود الحراري.
- **القيود المحاسبية الآلية واليومية**: قيود مزدوجة لحظية، مراكز التكلفة، وتعدد العملات وأسعار الصرف.
- **نظام التحديث التلقائي (Auto-Updater)**: التحقق من التحديثات وتنزيلها وتثبيتها بنقرة واحدة عبر GitHub مع أخذ نسخ احتياطية آمنة تلقائياً.

---

## متطلبات التشغيل / Requirements
- **Node.js** v18 أو أحدث - https://nodejs.org
- **Microsoft SQL Server** متصل بالشبكة
- **Windows** 10/11 / Server

---

## التشغيل / Quick Start

```bash
npm install
node server.js
```

أو النقر المزدوج على ملف `start.bat` أو `شغل_البرنامج.bat`.

افتح المتصفح على:
```
http://localhost:3000
```

---

## إعداد قاعدة البيانات / Database Configuration
يتم ضبط الاتصال بقاعدة البيانات عبر `db_config.json`:

```json
{
  "server": "YOUR_SERVER_IP",
  "port": "1433",
  "database": "hc",
  "username": "sa",
  "password": "YOUR_PASSWORD"
}
```
